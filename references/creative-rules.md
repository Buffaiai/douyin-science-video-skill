# 创作规范（画面与文案的硬约束）

对标账号：抖音「Vibe知识大赏」。验收方是用户本人，以下每条都对应过一次真实返工。

## 三段式配方

每期必须是 **情感悬念（钩子） × 硬核机制（可核实） × 人文升华（金句）**。

- 开场第一句用第二人称提问或反常识陈述，**不用概念名开场**。
  - 对：「为什么没说出口的话，最难忘」「你以为全场都在看你」
  - 错：「什么是蔡格尼克效应」「X 的原理」
- 中段顺序：机制 → 原始实验 → 新证据/元分析 → **诚实边界** → 按机制反推的 2~3 条做法。
- 收尾：中央大字金句（值得被截图转发）+ 一句回声，呼应开场问句。

## 标题

- 含「Vibe知识大赏」前缀与标点在内 **≤30 字**（建议 19~21 字留余量，中文一字算一位）。
- 公式：**第二人称 + 反常识或危机感 + 具体数字/画面**。带「为什么 / 你以为 / 其实」这类反转词。
- 每期给 1 个主推 + 2 个备选，字数标在括号里。

## 结构与时序

- 8~9 场，单场 330~660 帧，总 130~160 秒（4000~4800 帧 @30fps）。
- 典型场次序列：`hook → 概念母题 → 经典实验 → 新证据 → 谁最容易中招 → 诚实边界 → 三条路 → 升华 → 收尾金句`。
- 相邻场景重叠 18 帧（`OVERLAP`），淡入淡出 + 轻微缩放 + 镜尾一道斜向光扫，不硬切。

## 单一视觉母题（最容易失分的一条）

全片必须有**一个能贯穿始终的母题**，从第 0 帧出现、在片尾完成它：
- 未闭合发光圆环（蔡格尼克）· 1→32 翻倍的分岔路径（选择过载）· 每次被回忆就改字的字条（记忆重构）· 越接近越亮的跑道（目标梯度）。

禁止把一串互不相干的图解拼成片子。母题道具写成组件放 `kit.tsx` 的「本期道具」区，让它在多场复用并随剧情改变状态（开→合、亮→灭、翻倍→收敛）。

**系列签名**：上一期没收尾的母题元素，可以在本期结尾完成（例如让那个环闭合）。

## 画面纪律

- 主体必须是具象视觉隐喻/动效。大段文字占主画面会被打回。
- 文字只允许三种形态：① 底部一行字幕（`ChunkedSub`，白 + 金色关键词）② 数据/出处角标（`DataTag` / `SourceTag`）③ 金句场面的中央大字（`QuoteText`）。
- **绝对不画小人**：人形剪影、火柴人、五官四肢一律禁止。历史上两期因人形图形被判定"做不好"而整批重做。
  - 情感/人际选题用非人形符号替代：门=选择、笼子=困境、光=希望、动物=本能、物件=道具。
  - 语义上必须"有人"时，只用光斑、影子、色块暗示。
- **第 0 帧就要有完整内容**：主体轮廓先以低透明度常驻，不许全黑淡入（会被判"无完整内容"）。
- 右上角常驻 4 字主题水印，opacity≈0.7，暖金。
- 片尾**不放**「Vibe知识大赏」等活动落版大字；活动标识只进发布标题与话题。署名只留内容本身（如「洛伦兹吸引子 · 1963」）。
- 配色每期按选题重新设计，不沿用上一套（用户原话「风格不固定，使用你的最佳就好」）。但明度下限是硬的：底 `#10~#14` 量级、中心 `#26~#35`，不要近黑。
- 字体：宋体做主字幕与金句，苹方做角标，等宽做数值。

## 音频

工程内不做配音、不加 BGM（用户自己后期给）。交付前检查根目录有无 `s.wav` 或用户新放的音频：**有就直接混进成片**，截到与画面同止，末尾不留多余音频。
素材看着像旧文件时只提醒一次，用户拍板后照做，不反复阻拦（同一个 s.wav 已连续多期混用）。

## 数据经验（决定下期做什么）

表现最好的一条是蔡格尼克期（1.2 万播放，2026-10-12），它验证过的组合就是提议选题的模板：
1. 情感悬念句开场；2. 单一视觉母题贯穿；3. 机制解释 + 量化数据角标（ρ=.38 这类）+ 结尾金句。

用户来报数据时，他真正在意的是「这条为什么行」，回答要落在钩子与选题特征上，不是复述数字。
